# Preview the plugins

This site references the plugin projects in this checkout, not their published
NuGet packages. Change a plugin, rebuild, and inspect the generated page source.

The Open Graph title should combine this post's title with the site title.
The Twitter creator should be `@post-author`, overriding the configured default.

Visit [the fallback example](fallbacks) and [the about page](about) to compare
document and site defaults. Google Analytics is not enabled by default.
